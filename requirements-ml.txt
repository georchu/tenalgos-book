# Nothing else in the book needs this. Chapters 5-10 and 16 run on

# and read Chapter 11 rather than running it. You lose one sleeve that the
# book concludes is not worth its operational cost anyway (11.7).
#
# ---------------------------------------------------------------------------
# macOS: install the OpenMP runtime FIRST
# ---------------------------------------------------------------------------
# LightGBM links against libomp.dylib, which Apple does not ship. Without it
# the import fails at load time with:
#
#     OSError: dlopen(.../lib_lightgbm.dylib): Library not loaded:
#     @rpath/libomp.dylib
#
# The fix, with Homebrew:
#
#     brew install libomp
#
# If you do not have Homebrew, either install it from https://brew.sh, or use
# conda instead, which bundles the runtime:
#
#     conda install -c conda-forge lightgbm
#
# ---------------------------------------------------------------------------
# Linux: usually works as-is. If not, install libgomp1 from your package
# manager. Windows: works as-is.
# ---------------------------------------------------------------------------
