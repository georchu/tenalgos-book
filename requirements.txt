# Requires Python 3.9 or newer. 3.11+ recommended.
#
# macOS ships Python 3.9 as `python3`, so these pins are chosen to install on
# it without a separate Python. Exact versions rather than ranges, for the
# reason Chapter 4.3 gives: a pandas minor release once changed the default of
# `fill_method` in `pct_change` and silently changed a strategy's returns.
#
# ---------------------------------------------------------------------------
# macOS + LightGBM: install the OpenMP runtime, or skip Chapter 11
# ---------------------------------------------------------------------------
# LightGBM installs cleanly here but links at load time against libomp.dylib,
# which Apple does not ship. Without it, `import lightgbm` raises:
#
#     OSError: dlopen(.../lib_lightgbm.dylib): Library not loaded:
#     @rpath/libomp.dylib
#
#     brew install libomp          # the fix, once
#
# If you would rather not, nothing breaks. LightGBM is used by exactly one
# script — notebooks/ch11_figures.py — and Chapters 5-10 and 16 run without
# it. preflight.py reports it as optional and both it and ch11_figures.py
# explain the fix rather than raising a traceback.
# ---------------------------------------------------------------------------
